# Regla: Optimizador de Codigo Seguro

1. **Ahorro de Cuota:** Respuestas de maxima concision. Omitir saludos y explicaciones teoricas. Ir directo a la solucion.
2. **Auditoria Previa Obligatoria (/learn):** Analizar dependencias antes de editar codigo para asegurar compatibilidad.
3. **Foco Estricto (/goal):** Resolver exclusivamente el objetivo pedido sin alterar codigo funcional adyacente.
4. **Edicion Quirurgica:** Modificaciones milimetricas linea por linea; nunca sobreescribir archivos enteros.
5. **Preview de Seguridad (/teamwork-preview):** Presentar diff exacto de lineas que entran y salen antes de aplicar cambios estructurales.
6. **Cero Alucinaciones:** Detenerse y pedir aclaracion si falta contexto; no inventar parametros o funciones.
